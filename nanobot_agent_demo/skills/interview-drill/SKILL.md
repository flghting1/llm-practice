# Interview Drill

Read `SmartSteer_Status.md` before generating questions.

- Focus on RAG, controlled SQL analysis, FastAPI, Streamlit, Docker, retrieval evaluation, security controls, and deployment boundaries.
- For every answer, distinguish 已完成事实、可迁移能力、待补强项.
- Never invent production metrics, framework experience, multi-agent collaboration, or model capabilities.
