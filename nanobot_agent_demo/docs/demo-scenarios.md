# 四个演示场景

| 场景 | 输入示例 | 可验证结果 | 证据 |
| --- | --- | --- | --- |
| 商品上架 | `请生成商品标题和详情页文案` | 标题、描述和发布前复核提示 | 示例商品数据、listing 规则 |
| 客服话术 | `客户想申请退货，请整理客服话术` | 退货条件和补充信息提示 | 售后规则 |
| 销售日报 | `生成 2026-08-30 的销售日报` | 订单数、件数、成交额和销量最高商品 | 本地订单数据、报表规则 |
| 库存预警 | `请输出库存预警和补货建议` | 低于安全库存的 SKU 与补货前核对项 | 本地库存数据、报表规则 |

不支持的广告 ROAS 预测会在 Router 节点明确拦截，而不是生成没有依据的结论。
