# Docker 官方文档要点

资料来源：https://docs.docker.com/get-started/

Docker 可以把应用代码、运行时和依赖封装成镜像，再从镜像启动相互隔离的容器。

## 镜像与容器

镜像是只读的应用模板，容器是镜像运行后的实例。同一个镜像可以启动多个容器。

## Dockerfile

Dockerfile 描述镜像构建过程。常用指令包括：

- `FROM`：指定基础镜像
- `WORKDIR`：设置工作目录
- `COPY`：复制文件
- `RUN`：执行安装命令
- `EXPOSE`：说明服务端口
- `CMD`：指定容器启动命令

## 构建镜像

使用 `docker build` 根据 Dockerfile 构建镜像。修改程序代码后，通常需要重新构建镜像，旧镜像不会自动包含新代码。

## 运行容器

使用 `docker run` 从镜像启动容器。参数 `-p 8001:8001` 表示把宿主机的 8001 端口映射到容器的 8001 端口。

## 网络监听

容器内的 Web 服务通常需要监听 `0.0.0.0`，如果只监听 `127.0.0.1`，宿主机可能无法通过端口映射访问。

## 数据与安全

密钥不应直接写进 Dockerfile 或镜像。可以通过环境变量或部署平台的密钥管理功能注入配置。

`.dockerignore` 可以避免把虚拟环境、缓存、Git 数据和不必要文件复制进构建上下文。
