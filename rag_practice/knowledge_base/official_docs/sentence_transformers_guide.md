# Sentence Transformers 官方文档要点

资料来源：https://www.sbert.net/

Sentence Transformers 用于将句子、段落和文档转换为固定长度的向量表示，常用于语义搜索、文本相似度和聚类。

## Embedding

Embedding 是文本的数值向量表示。语义相近的文本通常在向量空间中距离更近，即使它们没有使用完全相同的关键词。

## 语义搜索

语义搜索会分别计算查询和文档的向量，然后使用余弦相似度等方法进行排序。与关键词搜索相比，它更容易识别同义表达和自然语言改写。

## 向量归一化

当向量使用 `normalize_embeddings=True` 归一化后，可以使用向量点积计算余弦相似度。这样能够简化相似度计算。

## 查询与文档

检索时需要保证问题和知识库文档使用兼容的模型生成向量。更换 Embedding 模型后，已有文档向量通常需要重新生成。

## 批量编码

实际项目应批量生成文档向量并进行缓存，不应该在每次请求时重新编码全部知识库，否则文档数量增加后响应时间会明显上升。

## 模型选择

模型选择需要考虑语言、准确率、向量维度、运行速度和资源占用。中文项目应通过固定评测集比较候选模型，而不是只根据模型名称决定。
