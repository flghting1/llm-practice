# RAG 基础

RAG 的全称是 Retrieval-Augmented Generation，中文通常译为检索增强生成。

一次完整的 RAG 流程通常包括：

1. 读取和整理原始文档。
2. 将文档切分成适合检索的文本片段。
3. 使用 Embedding 模型把文本转换为向量。
4. 将用户问题也转换为向量。
5. 计算问题向量与文档向量之间的相似度。
6. 召回最相关的文档片段。
7. 将召回内容和用户问题一起交给生成模型。
8. 返回答案，并展示引用来源。

RAG 的主要价值是让模型回答时参考外部资料，从而减少完全依赖模型记忆造成的错误。

如果检索不到足够相关的资料，系统应该明确说明无法根据现有资料确定，而不是编造答案。
