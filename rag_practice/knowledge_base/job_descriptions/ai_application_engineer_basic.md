# AI 应用工程师岗位摘要

## 岗位方向

基础 AI 应用落地岗位，重点是使用现有 AI 工具和大模型解决内部业务提效问题，不以模型训练或复杂算法研发为主。

## 主要职责

- 梳理办公和业务流程中的 AI 提效场景。
- 搭建和调试基础知识库、智能问答和文本处理功能。
- 优化 Prompt 与 AI 输出，保证功能适配业务使用。
- 维护已上线 AI 功能，排查问题并进行简单迭代。
- 整理 AI 使用方案，协助业务人员落地工具。

## 技术要求

- 掌握 Python 基础语法。
- 了解大模型调用和简单 API 使用。
- 了解基础 AI 知识库搭建和 Prompt 优化。
- 能独立完成基础 AI 应用落地，并具备良好沟通能力。

## 加分项与面试重点

- 有知识库、智能办公或文本 AI 处理项目经验。
- 能解释 RAG 流程、Prompt 调整和 AI 输出测试方法。
- 能说明如何处理上线后的错误反馈和迭代需求。
