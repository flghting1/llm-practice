# AI 应用开发工程师岗位摘要：全流程与 Agent 方向

## 岗位方向

负责 AI 应用从需求分析、架构设计、开发调优到上线部署的完整流程，重点涉及 Agent、RAG 和后端服务。

## 主要职责

- 参与 AI 应用从 0 到 1 的需求、架构、开发、调优和部署。
- 设计 Agent 架构，优化意图理解、任务规划和工具调用。
- 开发高可用、可扩展的 AI 应用后端服务。

## 技术要求

- 理解 Agent 和 RAG 的技术原理与系统架构。
- 掌握 Python、Java 等至少一门编程语言。
- 具备扎实的后端开发和软件工程基础。
- 能将模糊业务需求拆解成可执行技术方案。

## 面试重点

- 如何设计一个 Agent 的工具调用流程。
- RAG 与 Agent 的职责边界和组合方式。
- 如何处理后端服务的可靠性、并发和可扩展性。
