# AI Agent 后端工程师岗位摘要

## 岗位方向

面向金融业务场景开展 Agent 应用研发，关注智能交互流程、后端服务、模型集成和生产环境可靠性。

## 主要职责

- 设计和落地智能投顾、自动化运营或风险分析等 Agent 场景。
- 开发 Agent 后端服务，集成模型并进行性能优化。
- 保障生产环境的高可用性，并持续跟踪 AI 技术发展。

## 技术要求

- 有 Agent 开源框架的实际使用经验。
- 扎实掌握 Java、Spring Boot、多线程、JVM 和常见中间件。
- 了解 LLM 调用、Agent 框架和 RAG 流程。
- 具备 GitHub 活跃记录或可展示的开源项目更有优势。

## 加分项与面试重点

- 了解金融业务或高并发系统设计。
- 能解释 Agent 后端的权限、重试、日志和故障处理。
- 能展示一个可运行的 Agent 或 RAG 项目。
