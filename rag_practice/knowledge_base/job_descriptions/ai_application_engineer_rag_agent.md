# AI 应用开发工程师岗位摘要：RAG 与工具调用方向

## 岗位方向

使用大模型 API、RAG 和 Agent 框架开发企业级 AI 应用，覆盖后端接口、前端交互、知识库和部署迭代。

## 主要职责

- 基于大模型 API 开发企业级 AI 应用和后端接口。
- 完成文档解析、文本分块、向量入库和检索调优。
- 开发 Prompt、工具调用、会话流程和智能体功能。
- 参与测试、部署、Bug 修复和技术文档编写。

## 技术要求

- 熟悉软件系统设计和 AI 应用开发流程。
- 掌握 React、TypeScript 及 FastAPI 或 Flask 等框架中的部分技术。
- 了解 RAG 原理，有知识库搭建经验。
- 能使用至少一种 AI 编程或 Agent 工具。

## 面试重点

- 如何解决知识库更新和检索准确率问题。
- 如何设计工具调用和会话流程。
- 如何把 AI 应用从本地开发推进到测试和部署。
