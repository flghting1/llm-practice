# AI Agent 工程师岗位摘要：智能硬件与边缘部署方向

## 岗位方向

开发结合智能硬件和边缘计算的 AI Agent，涉及工具调用、知识检索、设备数据采集、模型服务和现场部署。

## 主要职责

- 开发 Agent 的工具调用、任务编排、上下文管理和知识检索功能。
- 开发 API、数据库、消息队列和异步任务等后端模块。
- 对接摄像头、传感器、网关、机器人和边缘设备。
- 集成 LLM、视觉模型和其他 AI 服务。
- 在 Linux 服务器和边缘设备上部署、调试和维护应用。
- 根据日志、接口数据和设备状态定位问题。

## 技术要求

- 掌握 Python 或 Node.js，并具备后端服务开发经验。
- 了解 API、数据库、消息队列、异步任务和并发处理。
- 了解 Tool Calling、Function Calling、工作流编排、RAG 或 Agent。
- 熟悉 HTTP、WebSocket、MQTT 或其他设备通信协议中的部分技术。
- 了解 Linux、Docker 和边缘计算部署环境。

## 加分项与面试重点

- 有 Agent 与智能硬件结合的项目经验。
- 有设备管理、远程诊断、边缘容器或云边协同经验。
- 面试可重点准备：如何处理设备离线、网络异常、模型超时和日志排查。
