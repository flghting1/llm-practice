# AI 应用开发工程师岗位 JD

## 岗位职责

1. 使用 Python 开发基于大模型的应用服务。
2. 使用 FastAPI 封装问答、检索和模型调用接口。
3. 建设 RAG 知识库，完成文档清洗、切分、Embedding 和向量检索。
4. 设计 Prompt、结构化输出和异常处理流程。
5. 编写评测脚本，分析召回率、响应时间和答案质量。
6. 使用 Docker 完成应用打包和部署。

## 任职要求

1. 熟悉 Python、HTTP、JSON 和 Git。
2. 了解 FastAPI、Pydantic 和 REST API。
3. 了解 RAG、Embedding、TopK 检索和来源引用。
4. 能阅读日志并定位常见代码或依赖问题。
5. 具备基本的测试、评测和文档编写能力。

## 面试重点

- RAG 的完整流程是什么？
- 为什么文档切分需要 overlap？
- 如何判断检索结果是否相关？
- 如何降低模型幻觉？
- 为什么 Docker 中的服务要监听 0.0.0.0？
- 如何设计一个可观测的 AI 问答服务？

## 来源说明

本文档是用于 RAG 项目测试的模拟岗位 JD，不对应具体公司或真实招聘信息。
