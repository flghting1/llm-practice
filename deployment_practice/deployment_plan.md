\# AI 项目统一部署链路



\## 目标



把已完成的项目统一整理为可复现的部署流程：



1\. 本地代码检查

2\. 自动化测试

3\. Docker 镜像构建

4\. 容器启动

5\. 健康检查

6\. API 验收

7\. 停止并清理容器

8\. 记录部署结果



\## 已纳入项目



\- RAG 求职知识库助手

\- SQL 数据分析 Agent

\- 简历与 JD 匹配助手



\## 当前部署端口



\- RAG API：8001

\- SQL Agent API：8004

\- 简历匹配 API：8006



\## 部署验收标准



\- Docker 构建成功

\- 容器状态为 healthy

\- `/health` 返回成功

\- 核心接口返回预期 JSON

\- 不提交虚拟环境、数据库、日志和真实隐私数据
