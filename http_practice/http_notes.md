# HTTP / API / JSON 学习记录

## HTTP 请求组成

- Method: GET、POST 等请求办法
- URL: 接口地址
- Header: 认证信息、内容类型等元数据
- Body: POST 请求提交的数据
- Query/Path: URL 中的参数

## GET 与 POST

- GET 通常用于读取资源。
- POST 通常用于提交数据或触发处理。
- POST 数据一般放在请求 Body 中。

## 常见状态码

- 200: 请求成功
- 400: 业务规划拒绝请求
- 401: 缺少身份凭证
- 403: 凭证错误或没有权限
- 404: 资源不存在
- 422: 参数类型或格式校验失败
- 500: 服务器内部错误

## 为什么使用 JSON

JSON 字段固定，前端和后端都可以解析，适合接口返回、结构化输出、日志和数据库处理。

## 为什么 API Key 不能放前端

前端代码会发送到用户浏览器，用户可以查看其中的密钥。API Key 应由后端从环境变量读取。
