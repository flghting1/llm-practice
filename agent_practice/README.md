# Agent 与工具调用练习

这是一个用于理解 Agent、工具白名单、状态记录和失败重试的最小练习。

当前版本没有调用真实大模型，Agent 的决策暂时由固定规则完成。

## Agent 流程

```text
用户问题
→ 判断要调用的工具
→ 生成固定工具调用结构
→ 检查工具白名单
→ 执行工具
→ 观察执行结果
→ 必要时最多重试一次
→ 返回最终回答


## SQL Agent

SQL Agent 将自然语言问题转换为受控的只读 SQL，再执行查询并解释结果。

### 已实现功能

- SQLite 用户、产品、订单三张表
- 数据库 Schema 文件
- 自然语言问题分类
- 固定 SQL 模板
- 只读 SQL 工具
- 只允许 SELECT
- 只允许单条 SQL
- 只允许访问白名单表
- 最多返回 100 行
- SQL 查询结果解释
- Agent 决策与观察状态
- JSONL 工具调用日志
