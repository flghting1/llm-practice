# 个人作品集网站

静态作品集首页，重点展示三个主项目：RAG 求职知识库助手、受控 SQL 数据分析 Agent 和 Nanobot 电商运营 Multi-Agent 原型。

网站包含项目源码入口、带旁白的完整演示视频、固定评测范围说明和目标岗位匹配信息。Nanobot 项目使用本地模拟数据，视频保存在
`assets/`，随静态网站一并部署；除公开下载的最终简历外，不在本目录保存密钥、个人敏感材料或运行日志。

当前公开下载的最终简历为 `assets/cheng-shihong-ai-application-engineer-resume.pdf`。更新简历时，使用同名文件替换并重新验证下载链接。

## 本地预览

在本目录执行：

```text
py -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 上线

网站由服务器上的 Nginx 托管。部署前使用 GitHub 推送本目录，然后在服务器克隆仓库并将本目录链接到 Nginx 站点目录。

不在本目录保存私钥、除公开下载简历外的个人敏感材料或任何运行日志。
