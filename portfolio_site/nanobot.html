NANOBOT / E-COMMERCE MULTI-AGENT

Nanobot 电商运营
Multi-Agent。

基于 Nanobot 的兼容入口，使用 LangGraph 编排 Router、Knowledge、Data、Content、Review、Finalizer 六个节点。项目提供 FastAPI 与 React 界面，覆盖商品文案、客服话术、销售日报和库存预警四类本地演示场景。

01 / ROUTER

识别商品文案、客服、日报或库存预警等受支持的运营请求。

02 / KNOWLEDGE

检索本地 Markdown 运营规则，为后续节点提供可追溯依据。

03 / DATA

对本地 SQLite 模拟订单、商品和库存执行只读查询。

04 / CONTENT

基于已批准的证据整理运营草稿；模型调用为可选能力。

05 / REVIEW

检查结论是否有来源支撑，并拦截不符合规则的高风险表述。

06 / FINALIZER

输出最终结果、审核状态、风险提示、来源与完整执行轨迹。

本项目仅提供本地演示，不托管模型密钥或公网 API。React 界面由 Docker Compose 在本机启动；Nanobot WebUI Skill 保持兼容，但不是本项目的主要演示入口。订单、商品、库存与规则均为本地模拟数据，未连接真实店铺或广告平台。
